¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Es como el esqueleto de una página web, definiendo su estructura básica. Fue creado por Tim Berners-Lee en 1991 y ha evolucionado hasta su versión actual HTML5.

Características principales:

  • Usa etiquetas para definir diferentes elementos
  • Es la base de cualquier página web
  • Trabaja en conjunto con CSS y JavaScript
  • Es fácil de aprender y usar
